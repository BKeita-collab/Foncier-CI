Géocodeur d'adresses

Convertissez une adresse en coordonnées GPS — prêt à copier dans professionnels.json

Rechercher une adresse

Entrez l'adresse du professionnel. La recherche est limitée à la Côte d'Ivoire.

Source : OpenStreetMap Nominatim — gratuit, sans clé API

Générer l'entrée JSON

Complétez les informations du professionnel, puis copiez le JSON dans data/professionnels.json.

ID et coordonnées GPS remplis automatiquement depuis la sélection. 
Sélectionnez un résultat pour générer le JSON.

Collez ce bloc dans le tableau de data/professionnels.json, après la dernière entrée existante (avant le ] final). N'oubliez pas la virgule après l'entrée précédente.
